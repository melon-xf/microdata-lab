# GSS 2024 — Source Selection Note

## Source
General Social Survey (GSS), NORC at the University of Chicago.
Stata single-year file: `https://gss.norc.org/get-the-data/stata.html`

## Access
Public download. NORC terms require a click-through acknowledgement but
assert copyright over all website contents. **Redistribution requires
express written consent from NORC** (`contracts@norc.org`).

## Platform treatment
This adapter downloads GSS data to the local lake for analysis under a
`personal_use_only` flag. The release is marked `redistributable: false`.
GSS data **must not** be included in any public release of this platform
until NORC grants written permission.

## Record unit
Adult respondent (person-level).

## Universe
Non-institutionalized adults aged 18+ in the United States.

## Weight
`wtssps` — the GSS sample weight for cross-sectional analysis.
For GSS Next follow-on variables, use `wtssps_next`.

## Variables inspected
- `year`: 2024
- `happy`: 1=Very happy, 2=Pretty happy, 3=Not too happy
- `sex`, `race`, `degree`, `age` demographics
- 989 total variables

## Benchmark
No GSS-derived benchmark value ships in the public repository. Local users
should compare weighted estimates against GSS Data Explorer before accepting
a result.

## Known limitations
- Stata file has non-unique value labels in `isco08`; must read with
  `convert_categoricals=False`.
- No replicate weights in single-year file; variance estimation requires
  the cumulative file or GSS Next panel weights.
- NORC copyright restricts redistribution.

## Release
GSS 2024 Release 3a (July 2026).
