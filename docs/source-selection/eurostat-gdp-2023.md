# Eurostat Statistics — Source Selection Note

## Source
Eurostat JSON API v1 at `https://ec.europa.eu/eurostat/api/dissemination/statistics/1.0/data/`

## Access
Public, no registration required. EU open data license (CC-BY-4.0 compatible).

## Dataset
`nama_10_gdp` — GDP and main components (annual), current prices, million euro.

## Benchmark
Germany (DE) GDP at market prices (B1GQ), current prices (CP_MEUR), 2023: **€4,219,310 million** — matches Eurostat official figure.
