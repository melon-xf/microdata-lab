# 04 — Typography, Titles & Annotation

Sources: Schwabish ch. 3 + style-guide ch. 12 [S], Knaflic ch. 4–5
[K], Cairo ch. 3 [C].

## Titles state the finding ("active titles")

All three authors: the title says what the chart *shows*, not what it
*is*.

- S: "active titles" — "Rising costs in Switzerland have led to a sharp
  increase in health care spending", never "Health care spending per
  capita in Switzerland" [S pp. 56–57]. The 5-second test: what is this
  chart saying? [S p. 56]
- K: action titles — "Estimated 2015 spending is above budget", not
  "2015 Budget" [K doc 13]. Sentence case (first word capitalized —
  faster to read) [K doc 16].
- The headline must survive contact with the data: "price declined for
  ALL products" was wrong; the corrected headline scoped the claim
  [K doc 16]. **Verify every headline against the numbers it
  summarizes.**
- Title placement: upper-left-most, where the z-pattern starts
  [K doc 11; S p. 372]. Don't center it.

## Direct labeling beats legends

Consensus, one of the strongest cross-book rules:

- "Eliminating legends and directly labeling the data series is one of
  the best and easiest changes" [S p. 57]; legends force back-and-forth
  that breaks ~4-chunk working memory [K doc 12].
- Direct-label line ends when series are few; legend only as last
  resort [S pp. 364–365; K doc 11].
- Label color = data color (similarity) [K doc 11].
- Dumbbell/slope: legend text itself colored by series, placed
  upper-left [S p. 360].

## Annotation

- Annotation layer (Amanda Cox / Burn-Murdoch): title + subtitle +
  annotations + footnotes overlay [S pp. 53–54].
- **Subtitle/lede**: one sentence, left-aligned, sentence case — tells
  the reader what the chart shows, not just its topic [S pp. 372–373].
- Annotations explain nuance, mark events, define terms [K doc 13];
  keep to one or two lines, horizontal [S pp. 368–369].
- Reference lines/areas for thresholds (poverty line, target, parity)
  [S pp. 369–370].
- Don't assume two people draw the same conclusion — state it in words
  [K doc 13]. "Text is your friend: label, introduce, explain,
  reinforce, recommend" [K doc 13].
- McCandless exception: an unlabeled axis is acceptable when relative
  peaks/valleys are the point and the omission is deliberate — rare
  [K doc 13].

## Type rules

- One or two typefaces total [S p. 363; C p. 152]; sans-serif for
  labels/numbers; bold > italic > underline for emphasis (underline
  adds noise) [K doc 13].
- UPPERCASE only for short sequences (titles, keywords) [K doc 13].
- No large colored or all-caps body text [S p. 363].
- Sentence case titles; axis titles on BOTH axes, exceptions "extremely
  rare" [K doc 13]; axis title aligned to the outermost label
  [K doc 16].
- Horizontal text only: 45° rotation = 52% slower, 90° = 205% slower —
  rotate the chart, never the text [K doc 11; S p. 371].
- Left-justify everything (centered text has no clean edge) [K doc 11].
- Footnote/source line: small, gray, bottom-left [K doc 14].

## Numbers as text

- Keep $/%/, attached to numbers [K doc 11].
- Strip trailing zeros; precision matched to the unit (no fractions of
  a person) [K docs 11, 13].
- pp vs % explicit when both appear [S pp. 21–22].

## Renderer checklist

- [ ] Title = active sentence, verified against the data, upper-left,
      sentence case
- [ ] Subtitle/lede present, one sentence
- [ ] No legend when ≤3 series; direct labels at line/bar ends
- [ ] All text horizontal; left-justified
- [ ] Axis titles both axes (or documented rare exception)
- [ ] Source/footnote line present
- [ ] Reference lines for declared thresholds
