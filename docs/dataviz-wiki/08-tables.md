# 08 — Tables

Sources: Schwabish ch. 11 (from his "Ten Guidelines for Better
Tables") [S], Knaflic ch. 2 [K], Cairo [C].

## When a table beats a chart

- Precision matters more than pattern; readers look up individual
  values [S pp. 341–342].
- Mixed audiences each finding their own row [K doc 10].
- Multiple units of measure in one view [K doc 10].
- "If the bubbles have no functional purpose, why not design a simple
  and honest table?" [C p. 46].
- NOT in live presentations — the audience reads and stops listening
  [K doc 10].

## Schwabish's ten rules [S pp. 342–352]

1. **Strip the gridlines**: all or most; heavy grids cage the data.
2. **Right-align numbers** (decimal-align when precision varies);
   left-align text; center nothing by default.
3. **Round deliberately**: 2–3 significant digits; consistent precision
   per column.
4. **Thin type, sparse bold**: bold for headers/totals only.
5. **Give it a title** (active where possible) + units in headers.
6. **Group with white space**, not rules; row spacing rhythm.
7. **Order by content**: meaningful sort (value, alphabet, group), not
   accident.
8. **Guide with subtle rules**: header underline + total overline only.
9. **Highlight the takeaway**: one cell/row/column in accent; heatmap
   saturation for pattern-in-numbers.
10. **Add micro-visualizations**: sparklines, in-cell bars, heatmap
    shading, dot columns.

## Knaflic's table rules

- "The data should be what stands out, not the borders" [K doc 10].
- Heatmap = table + saturation cue; ALWAYS include the LOW–HIGH legend
  [K doc 10].
- Fade to background: light gray or no borders [K doc 10].

## Special tables

- **Regression/results tables**: real words, not variable names;
  asterisks + SE; dense version to appendix, dot-and-whisker of
  coefficients in the body (solid = significant, hollow = not)
  [S pp. 351–352].
- **Dashboard tables**: heatmap + sparkline hybrids; USDA redesign
  found the Oklahoma pattern only after adding saturation [S pp. 348–351].

## Renderer checklist

- [ ] Gridlines removed or hairline-gray
- [ ] Numbers right/decimal-aligned; text left
- [ ] ≤3 significant digits
- [ ] Active title + unit-labeled headers
- [ ] Takeaway row/column highlighted
- [ ] Heatmap legend present when saturation used
