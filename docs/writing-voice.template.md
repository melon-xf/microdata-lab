# Writing voice — questionnaire

Fill this in with a person in the loop. An agent runs the prompts one batch at
a time, the person answers in their own words, and the agent waits between
batches. Aim for 15–20 short samples total. When the exercise is done, paste
the agreed rules and the best samples into `docs/writing-voice.md`, replacing
its generic guidance.

## Batch 1

1. Rewrite an actual line from this repository that reads like AI copy. Quote
   the file and line first.
2. Write the error message for: a source download failed its checksum.
3. Write the error message for: a survey release is missing a required
   artifact.
4. Write the error message for: you hit an API rate limit.

## Batch 2

5. Describe Microdata Lab to a stranger at a party, in two sentences.
6. Write the empty state for "no analyses in this catalog yet."
7. The one piece of praise for a passing analysis that would not make you
   cringe.
8. Text a friend about something that went wrong today.

## Batch 3

9. Three phrases that make you want to close a tab.
10. Rewrite a chart title from this repository that reads like a slogan.
11. Write the note under a chart that shows a descriptive finding, without
    implying a cause.

## After ~8 samples

Stop and write a voice hypothesis: five to eight concrete, falsifiable rules
(rhythm, sentence length, punctuation habits, praise, bad news, refusals).
Then test it on one piece of repository copy with three variants, and ask
which is closest and why. Revise the rules from the correction. Repeat until
the person says it is right.

## Voice target

Dry and flat. Understatement, not jokes. Quippy or winking lines missed.

## When done

Paste the agreed rules and the best samples into `docs/writing-voice.md`,
replacing its generic guidance. Do not paste the filled questionnaire
anywhere else.
