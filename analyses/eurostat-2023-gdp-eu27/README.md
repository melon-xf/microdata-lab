# GDP Across EU-27 Member States, 2023

## Methods

Analysis of the Eurostat nama_10_gdp dataset (GDP and main components, annual) via the Eurostat JSON API v1. GDP at current market prices (million euro) was extracted for each EU-27 member state for 2023.

## Results

Germany (€4,219B) leads the EU-27 by a wide margin, followed by France (€2,834B), Italy (€2,143B), and Spain (€1,498B). The smallest member states — Malta and Cyprus — have GDPs below €30B.

## Limitations

- GDP in current euros does not adjust for PPP or cost of living.
- No sampling variance; official macrodata.
- Data may be revised in subsequent Eurostat releases.

## Source

Eurostat Statistics (JSON API v1), nama_10_gdp dataset. Release `eurostat-2023-ec3202b3765b`.
