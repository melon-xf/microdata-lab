# Question and estimand

## Question

How does GDP compare across EU-27 member states in 2023?

## Estimand

GDP at current market prices (million euro) for each EU-27 member state in 2023.

## Record unit and universe

- Record unit: country-year observation.
- Universe: all 27 EU member states with GDP data for 2023.
- Exclusions: EU aggregates (EU27_2020, EA, EA19) excluded; only individual member states included.

## Variables and definitions

- `B1GQ`: Gross domestic product at market prices.
- `CP_MEUR`: Current prices, million euro.
- `geo`: EU member state code (ISO 2-letter).
- `geo_label`: Member state name.

## Design and uncertainty

No survey design. Official macrodata — no sampling variance.

## Release

- Release ID: `eurostat-2023-ec3202b3765b`
- Source: Eurostat JSON API v1 (nama_10_gdp dataset)
